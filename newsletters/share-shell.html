VIPs of ceramic: the newsletter in live text

The VIP newsletter rebuilt as a Mailchimp template: real text instead of pictures of text, the same design, one column on a phone. The VIP code below is a sample; each guest gets their own.

Compared with the image version

  • Readable with images off, so it no longer looks like spam. Untick "Images on" to see.
  • Same layout, colours and photos; the title over the photo is real text.
  • Two columns on a computer, one on a phone, without a separate mobile version.

What Félicie can edit in Mailchimp

  • Every text, picture and button: click it and change it.
  • Every row can be duplicated or hidden.
  • Colours and font sizes in the Design tab, so the monthly, galleries and Basel themes reuse the same template.
